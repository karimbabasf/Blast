04Pay on proof

Money moves only for proof

Claude pays over Stripe's machine payments with a capped token. The payment is a hold, captured only when the winner passes, and the builder is paid through Connect.

Stripe MPP + Connect
lib/pay/proof.ts
// Claude pays over MPP (HTTP 402 + a capped Shared Payment Token),
// but the PaymentIntent is only a hold
client.paymentIntents.create = (params, options) =>
  create({ ...params, capture_method: "manual" }, options);

// The winner passed every check: capture its price, pay its builder
await stripe.paymentIntents.capture(hold.payment_intent, {
  amount_to_capture: winner.price_cents,
});
await stripe.transfers.create({
  amount: Math.round(winner.price_cents * 0.8),
  currency: "usd",
  destination: winner.stripe_account, // the builder's Connect account
  source_transaction: chargeId,
});

// Nobody passed: release the hold, nobody pays
await stripe.paymentIntents.cancel(hold.payment_intent);
