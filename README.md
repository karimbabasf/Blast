# Blast

Hackathon project, 2026-10-03. Supabase Select 2026, theme "Build something agents want."

**A manager agent that auditions and hires other agents for you.**

You say what you want. One agent finds specialist agents, test-drives each on a small sample of your task, hires the best one, and pays it. You can approve each hire, or let it run on a budget.
